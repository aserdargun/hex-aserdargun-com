# HEX interface specification

Reference: `HEX/previews/design-concept.png`, generated with the built-in imagegen tool from the user brief. The user explicitly granted creative freedom and requested implementation.

Primary surface is a working explorer, with a 66–72 px masthead, 200 px system rail, large actual 3D viewport, and 300 px lesson rail. At laptop widths the headline scales and the rails narrow. On mobile: compact masthead, horizontally scrollable systems, full-width viewport and controls, then an accessible lesson panel. No controls rely exclusively on 3D picking.

Tokens: canvas #f4f5f2; ink #20282d; muted #59636d; rule #d3d8d8; accent #d94d2e; selected #fbe5dc. Neutral sans-serif with generous headline tracking, monospaced technical labels. Square/minimally rounded controls, hairline separators, no card grid. Shared buttons, rail rows, section captions, inspectors and range inputs. Small outline icons use Lucide.

Exact overview: “A body. A connected system.”, “Explore the engineering behind embodied intelligence.” Right: “More than a machine.” and the sense → estimate → control → actuate → sense again loop. CTA “Explore the knee”. Primary modes: Explore, Structure, Joints, Actuation, Sensors, Power, Compute, Perception, Control, Behavior. Real 3D occupies the media role, no rendered image stands in for interactivity.

Interactions: orbital navigation, camera bookmarks, progressive explosion, joint anatomy and scrub/play, named component selection, layer highlights, wiring paths, perception stages, guided chapters, language selection, information/sources dialog. Reduced motion pauses autoplay. All essential controls have keyboard alternatives and visible focus. The 3D failure state keeps learning content and rendered previews available.
